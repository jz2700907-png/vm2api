# 《站我这边》分镜剧本 v3（Claude × GPT 合并版）

非商业粉丝宣传片 · 约 3:05 · 16:9（2.39:1 遮幅）· 96 BPM，一小节 = 2.5 秒

## 一句话故事

从火星来的朱诺第一次见到地球，喜欢上了雨，也习惯了躲在莱因哈特的盾后面；一场暴雨中的撤离里，老兵独自断后，是她走回雨里，把他带了回来。

## 核心设计

- **主角**：朱诺（新人，火星出生，第一次来地球）+ 莱因哈特（老兵，习惯挡在所有人前面）。
- **变化**：朱诺从躲在盾后，到敢于替队伍做判断。莱因哈特从永远挡在前面，到愿意听她的、跟在她后面走。
- **贯穿线（三处都能用画面拍出来）**：
  - 雨：第一场雨让她惊奇，暴雨成了危险，雨后放晴时两人一起站在雨里。
  - 盾：先被当作雨伞，再用来挡子弹，最后碎了，他没有再举起来。
  - 台词“站我这边”：第一次是莱因哈特半开玩笑，第二次是莱因哈特下命令，第三次由朱诺对他说，角色互换。
  - 消息：朱诺写给火星上妈妈的消息。暴雨来时写到一半被打断，结尾才发出去。
- **地图的作用**：第一幕用朱诺的眼睛看地球，地图美景就是她的情绪，也是后面值得守护的世界。它不再是一段和主线无关的蒙太奇。
- **设定前提**：
  - 这是新守望先锋成立之后的一次原创任务，不是首次召回。
  - 朱诺是为了替火星殖民地求援才来到地球的。她妈妈是小美读研时的朋友，所以她叫小美“阿姨”。
  - 敌人是 Talon（毛加、黑百合、死神），在自定义比赛里就能录。

## 分镜

素材来源的写法：
- **录屏**：自定义比赛或回放的自由视角、第三人称，关闭 HUD。
- **AI**：只生成不出现角色脸的镜头。
- **后期**：由我合成，包括雨、消息界面、调色、字幕。

## 验证片段（先做这个）

先只做 3-02 → 3-05 → 3-06 → 3-07，约 20 秒：朱诺走进雨里，说“站我这边”，莱因哈特答“好，听你的”，轨道射线落下。

需要准备的素材：
- 艾兴瓦尔德的录屏：莱因哈特跪地、朱诺走出城门、朱诺放加速环、朱诺开大；
- 第 6、7 两句配音。

这一段能同时检验四件事：情绪能不能立住、技能的因果观众看不看得懂、两个人的走位、录屏和后期雨能不能接上。这段成立了，再做其余部分。

## 这一版和 GPT 意见的对应

- **采纳**：
  - 背景不用首次召回，删掉“三天前”；
  - 朱诺来地球的动机按官方设定；
  - 删掉“欢迎归队”“会有人来吗”“他们都来了”；
  - 高潮按战术因果拍：先占视野，再用冰墙截断火力，再放加速环，然后光柱沿撤离路线推进，莱因哈特跟着她走；
  - 情感高潮是莱因哈特说“好，听你的”；
  - 不拍拍肩、把人拉起来、细微表情这类难实现的镜头；
  - 暖光留到最后；
  - 删掉花村兄弟和解、天使接法杖；
  - 先确定敌人是谁；
  - 先做验证片段。
- **没有采纳**：
  - 地图压到 10～15 秒并插在撤离中段：改成放在第一幕，从朱诺的视角看；
  - 用撤离现场开场：改成先用一场不打仗的雨夜建立两人关系；
  - 撤离点用机库：改在艾兴瓦尔德；
  - “跟着光走”：换成“站我这边”，同一句台词出现三次，最后一次角色互换。
