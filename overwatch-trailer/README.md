# 世界需要更多的英雄 · 守望先锋同人宣传片

**The World Could Always Use More Heroes** — a 3 min 10 s fan-made promotional trailer for *Overwatch*.
Every frame, every note of the score and the narration are generated by code in this folder. The film
uses no game assets, samples or stock footage.

> 非官方粉丝致敬作品。守望先锋®（Overwatch®）是暴雪娱乐的商标，本片与暴雪娱乐无关，亦未获其认可。

成片 / Final cut: `overwatch_fan_trailer_1080p.mp4` (1920×1080, 30 fps, H.264 + AAC, 2.23:1 letterbox, burned-in Chinese/English subtitles).

## 怎么做出来的 / How it is made

- **Picture**: `index.html` plus `js/*.js`. This is a hand-written Canvas 2D engine with a 2.5D parallax camera and
  procedurally painted environments (fbm clouds, ridges, skylines, reflections). Heroes are silhouettes built on
  a small skeleton rig, with signature emissive details. Effects include bloom, god rays, lens flares, particles,
  hex barriers, spirit dragons and film grain. `js/gallery.js` renders a debug sheet of all heroes.
- **Score & sound design**: `tools/music.py` is an original 96 BPM score in D minor that resolves to D major.
  It is synthesised with numpy/scipy: PolyBLEP string ensembles, brass, a formant choir, additive piano,
  Karplus-Strong koto/guzheng, dizi-style flute, taiko and braams. Every cut and impact lands on the
  bar grid (1 bar = 2.5 s).
- **Orchestral score (v2)**: `tools/score.py` writes the same cue as MIDI, one file per section (sectional strings,
  horns, trumpets, trombones, choir, timpani/taiko, piano, harp, koto, shakuhachi…). It renders each part with real
  instrument samples (MuseScore General SF2 via fluidsynth: `apt install fluidsynth musescore-general-soundfont-lossless`),
  then balances the stems and mixes them in a convolution hall -> `build/score.wav`.
- **Narration**: `tools/vo.py` synthesises the Chinese voice-over offline with the Kokoro TTS model (sherpa-onnx),
  pitched down a semitone with light EQ, compression and room reverb.
- **Mix**: `tools/mix.py` handles narration ducking, bus compression and a look-ahead limiter.
- **Render**: `tools/render.js` drives headless Chromium frame by frame (deterministic `renderAt(t)`) across
  parallel workers and pipes JPEG frames into ffmpeg/libx264.

## 重新生成 / Rebuild

Requirements: Node 22 with the global `playwright` package and a Chromium, `ffmpeg` with libx264, and Python 3
with `numpy scipy soundfile sherpa-onnx`. You also need the
[`kokoro-multi-lang-v1_0`](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models) model.

```bash
python3 tools/fetch_fonts.py                 # Noto Sans SC / Noto Serif SC / Barlow Condensed -> fonts/
python3 tools/vo.py --model /path/to/kokoro-multi-lang-v1_0
python3 tools/build_data.py                  # story.json + vo timings -> build/data.js
python3 tools/music.py && python3 tools/mix.py
node tools/render.js --stills 12,47,125.5    # spot-check frames -> build/stills/
node tools/render.js --video --workers 4     # -> build/video.mp4
ffmpeg -i build/video.mp4 -i build/mix.wav -map 0:v -map 1:a -c:v libx264 -crf 20 -preset slow \
  -tune animation -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart overwatch_fan_trailer_1080p.mp4
```

`SHOTLIST.md` lists the gameplay footage and voice material for the footage-based cut.

`story.json` holds the scene timeline and narration script. Edit the lines there and rerun the pipeline to
change the story.
