# 验证片段录制清单（2:05–2:35，30 秒）

这段对应剧本 v4.1 里的镜头 3-02 到 3-07：朱诺从城墙上走下去，说“跟着我”，莱因哈特回答“好，听你的”，然后轨道射线落下。

要检验四件事：
- 情绪能不能立住；
- 技能的因果观众看不看得懂；
- 后期做的“暴雨黄昏”能不能接上；
- 配乐在 2:30 转大调的那一下落不落得准。

## 一、录制设置

- **地图**：自定义比赛，选艾兴瓦尔德（普通版）。攻城锤还没推到城门时，城门是关着的，正好就是剧本里“门关着”的状态。
- **录屏软件**：OBS、NVIDIA ShadowPlay 或 AMD ReLive 都可以。
  - 1920×1080，60 帧（后期需要慢动作）；
  - 码率 20 Mbps 左右（CBR 20000 Kbps）。
- **游戏画质**：拉到最高，关掉动态模糊。
- **镜头**：用观战位的自由视角或第三人称视角录，不要用第一人称。
  - 镜头移动越慢越稳越好；
  - 每条连续录 8～10 秒，一条里不要切镜头。
- **HUD**：在“设置 → 操作 → 观战”里找隐藏 HUD 的按键。头顶名字、描边这些实在关不掉也没关系，告诉我，我在后期裁掉或盖掉。
- **人手**：
  - 最理想是 3～4 个玩家（朱诺、莱因哈特、小美、毛加），再加 1 个观战位专门录像。
  - 只有你一个人也能录：告诉我，我给你写一段工坊（Workshop）代码，提供第三人称镜头，并能放置可以控制的假人（毛加开火、小美放冰墙、莱因哈特蹲下再站起来）。

## 三、配音（2 句）

| 台词 | 语气 | 要求 |
|---|---|---|
| 朱诺：“跟着我。” | **平静、笃定**，不喊，也不要哭腔 | 录 3 遍，快慢各不相同 |
| 莱因哈特：“……好，听你的。” | 先停一拍，低低笑一声，然后认真说 | 录 3 遍；声音压不低也别硬压，我可以在后期把音调略微降一点 |

- 手机录音就行：找衣柜或者盖着被子的角落，嘴离手机约 20 厘米。
- 每条录音开头先空 3 秒，录一段环境底噪，后期降噪要用。
- 导出 wav 或 m4a，不要加任何效果。

## 四、发给我的时候

- 每个文件不能超过 30 MB：按上面的码率，10 秒以内的片段大约 25 MB。
- 太长就先用手机或剪映剪短再发。
- 文件名按上表写，多遍就加 `_take2` 这样的后缀。
