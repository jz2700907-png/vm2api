# 《第一场雨》分镜剧本 v4（Claude × GPT 第二轮合并）

非商业粉丝宣传片 · 3:05（74 小节）· 16:9（2.39:1 遮幅）· 96 BPM，一小节 = 2.5 秒

## 一句话故事

从火星来的朱诺在地球上总是跟在别人后面，也总被莱因哈特挡在盾后。一次 Talon 的截击中，她被护送进城堡，莱因哈特在门外断后，被困在离城门十米的地方。朱诺翻出城墙，第一次对他说：“跟着我。”

## 相对 v3 的改动

| 问题（GPT 第二轮提出） | v4 的改法 |
|---|---|
| 救援因果不完整：为什么只有朱诺回去 | 1. 给 Talon 一个明确目标：他们要的是朱诺，狙击镜第一个锁定的就是她。<br>2. 莱因哈特自己喊“关门！”，城门在他身后关上。<br>3. 门内的人各有要事：猎空、卢西奥在对付翻进来的死神。<br>4. 城门一直被火力压着，不能开；只有朱诺能从城墙滑翔下去，同时还能治疗。<br>5. 温斯顿喊“朱诺，回来！”，说明有人拦过她。 |
| 护盾碎后几十秒不恢复，不符合游戏机制 | 3-01 加一个镜头：莱因哈特试着重新展开护盾，护盾闪了一下就被打碎。 |
| 第三次“站我这边”语义不成立 | 朱诺改说“跟着我。”它和莱因哈特在 1:00 喊的“跟紧我！”是精确的角色互换，也把第一幕“她总跟在别人后面”整段翻了过来。 |
| “一个都不能少”太熟 | 删掉。温斯顿的通讯改为：“带朱诺进城堡！”（交代目标），以及“朱诺，回来！” |
| “我们都没躲”和前面的战术矛盾 | 结尾改为：“妈，今天又下雨了。今天是我带的路。” |
| 盾不能当雨伞，游戏里它是竖直的 | 改成风里斜着下的雨打在竖直的盾面上，朱诺站在盾后背风的一侧。 |
| 第一幕像旅游片 | 每张地图都是朱诺跟在一个老英雄后面跑，同时第一次亲历地球。消息文字写出她一步步的状态：地球好重 → 迷路 → 跟不上 → 想家 → 被挡在后面。整段的作用是立住“她总在跟着别人”，高潮的“跟着我”把它翻过来。 |
| 小美阿姨缺少官方依据 | 改称“小美”。放灯拆成三个镜头：小美放灯、朱诺抬头、灯光映在面罩上。两人没有接触。 |
| 万圣节版和普通版混用，连续性有问题；南瓜装饰也会破坏气氛 | 全片统一用普通版艾兴瓦尔德。第二、三幕由我在后期做成“暴雨黄昏”，第四幕放开调色，回到地图原生的金色光线。 |
| 巴德里希只能暗示 | 不闪回、不解释。如果地图里能拍到十字军徽记，就让它在 3-01 的背景里出现一下，不给特写。 |
| 两次消息之间缺少信号恢复的动作 | 4-03 先拍信号格从红变绿，再拍消息发出。 |

GPT 这轮有两处说法我没有采用：
- **“1:50 到 2:30 有近 40 秒静音”**：v3 文件里只有第 49–50 小节这两小节是静音，第 51 小节起低音弦乐就进来了。是给它的摘要里没写清楚，v4 补上了低频脉冲。
- **“3:05 与小节不齐”**：185 秒 ÷ 2.5 秒 = 74 小节，正好对齐。

## 分镜

素材来源的写法：
- **录屏**：自定义比赛或回放的自由视角、第三人称，关闭 HUD。
- **AI**：只生成不出现角色脸的镜头。
- **后期**：由我合成，包括雨、消息界面、调色、字幕。

## 验证片段（先做这个）

先只做 3-02 → 3-04 → 3-05 → 3-06 → 3-07，约 20 秒。

需要准备的素材：
- 艾兴瓦尔德录屏：朱诺从城墙上跳下、朱诺落地放加速环、莱因哈特蹲在掩体后、朱诺开大；
- 第 6、7 两句配音。

这一段要检验三件事：
- 情绪能不能立住；
- 技能的因果观众看不看得懂；
- 我用后期做的“暴雨黄昏”能不能接得上。
