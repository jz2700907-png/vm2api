# 提示词 2：英雄角色和剧情镜头（给画面生成 AI）

适用：可灵、即梦、海螺、Runway、Midjourney、豆包等能生成视频或图片的 AI。
分成三类：**A. 英雄亮相**、**B. 剧情和大招镜头**、**C. 绿幕单独素材**（方便我合成进场景）。

---

## 先粘贴给 AI 的说明（整段复制）

```
我在做一部非商业的《守望先锋》粉丝宣传片，需要你按下面的描述逐个生成英雄角色的画面。要求：
1. 画风统一：暴雪CG动画短片风格，风格化3D，守望先锋美术风格，角色造型要尽量还原游戏里的样子。
2. 视频每段5–10秒，16:9，1080p，镜头缓慢平滑移动；只能出图就出16:9、至少2560×1440的图。
3. 画面里不要出现任何文字、字幕、logo、水印、游戏界面。
4. 人物放在画面中间，脸和手要自然，不要畸形。
5. 每个镜头生成2–4个版本。
下面是逐个镜头的描述。
```

## 每条提示词后面都加上的风格后缀

**中文**
```
，暴雪CG动画短片风格，风格化3D，守望先锋美术风格，手绘质感贴图，体积光，色彩饱和，电影宽银幕构图，浅景深，镜头缓慢平滑移动，超高细节，16:9
```
**English**
```
, cinematic shot from a Blizzard-style animated short film, stylized 3D, Overwatch art style, hand-painted textures, volumetric lighting, rich saturated colors, anamorphic widescreen composition, shallow depth of field, smooth slow camera movement, highly detailed, 16:9
```
**反向提示词 / Negative prompt**
```
文字, 字幕, logo, 水印, 游戏界面, 模糊, 低清, 手部畸形, 多余手指, 面部扭曲, 真人实拍

```
